REVISION 3 INTEGRATION

- Preserves all 194 existing shared army entries, 77 rules, and 501 profiles.
- Adds the Mjordhainn Raiders army list.
- Expands the existing Demiurg list into the Resource Raider Detachment while
  retaining every original Demiurg entry.
- Adds the Iron-head Prospectors, Prospector Exo-kyn, Demiurg Miners, Terror
  Termite, Sventaur Trikes, Spyder Platforms, Cargo-8 Road Train, Skalvian
  Explorator, Oreicke Mineral Drill, and Oreicke Defence Grid.
- Adds the Pirate Raiders list, directly linking eligible Jorgall, Demiurg, and
  Agents of the Imperium units already present in this catalogue.
- Adds the Umbra Umbral Conclave list.
- Adds the two supplied Greater Necrontyr C'tan Shards.
- Adds the Rangdan Sleeper Host list, including selectable host-form costs and
  the complete Lesser, Moderate, and Higher host-form reference.
- Retains the Zutan Scribes and expanded water rules.

SOURCE-LIMITED ITEMS

The supplied rules name Rangda Overlord, Legendary Cerabvore Host, Legendary
Osseivore Host, Oblivion Anathema, God Beast, Strain Reader, and God Killer but
do not provide enough rules or points to create honest selectable profiles.
They are preserved as clearly labelled reference material rather than invented.

Pirate Raider units from Eldar Corsairs, Dark Eldar, Militia and Cults, and
Blackshields use labelled external-source roster entries with repeatable one-point
cost trackers because those complete catalogues are not embedded in this file.

INSTALLATION

Repository method:

1. Upload index.bsi and Xenos_of_the_Great_Crusade_HH1.catz to the repository root.
2. In BattleScribe, add the raw index.bsi URL as a data repository.
3. Update data and select the Xenos of the Great Crusade catalogue.

Direct method:

Import Xenos_of_the_Great_Crusade_HH1.catz in BattleScribe alongside
The Horus Heresy game-system revision 165.
